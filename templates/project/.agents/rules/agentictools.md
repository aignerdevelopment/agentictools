# agentictools

All rules, skills, prompts, hooks, custom agents, workflows, MCP integrations and
tools live in the central **agentictools** repository. This project only
references them.

- Central repo: `{{AGENTICTOOLS_HOME}}`
- Selection: `agentictools.config.json`
- Enabled modules: `.agentictools/active.md`

Read `AGENTS.md` and the enabled modules listed in `.agentictools/active.md`.
Never add agentic artifacts to this project; add them to the central repo.
